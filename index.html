Algorithms

Seven Optimizers

All implemented in NumPy. Each exposes the same interface so they can be swapped and compared on any landscape.

01
Gradient Descent
x = x − lr · ∇f(x). The baseline — simple, predictable, slow on ill-conditioned problems.
O(1/k)
02
SGD (mini-batch)
Noisy gradient from a random mini-batch. Supports cosine, step decay, and warmup LR schedules.
Stochastic
03
Momentum (Heavy Ball)
Accumulates velocity across steps — dampens oscillations in ravines, ~3× faster on κ=1000.
β = 0.9
04
Nesterov AGD
Evaluates gradient at the look-ahead point instead of current position. Provably optimal O(1/k²) on convex functions.
O(1/k²)
05
AdaGrad
Per-parameter adaptive lr based on cumulative gradient history. Works well for sparse gradients but lr decays to zero.
Adaptive
06
RMSProp
Fixes AdaGrad's shrinking lr by using an exponential moving average of squared gradients instead of summing them.
EMA · ρ=0.9
07
Adam
Momentum + RMSProp + bias correction. The default choice in most deep learning pipelines.
β₁=0.9 · β₂=0.999

Results

Convergence Analysis

Loss vs Iterations — Ill-Conditioned Quadratic (κ = 1000)

Adam and Nesterov converge in ~50–80 iterations. Vanilla GD needs 400+ and still hasn't fully converged. Y-axis is log scale.

Learning Rate Schedules — Effect on SGD Convergence

Cosine annealing consistently outperforms fixed and step-decay schedules. The smooth decay avoids abrupt jumps that destabilize training.

Iterations to Convergence (f < 1e-5) by Landscape

GD's iteration count explodes on ill-conditioned problems. Adam and Nesterov scale much better. Rosenbrock remains hard for everyone.

Takeaways

What I Found

🏎️
Adam wins on ill-conditioned problems
On κ=1000, Adam converges in ~50 steps. Vanilla GD needs 500+ and still isn't fully there. The adaptive scaling handles the different curvatures in each direction.
📉
Nesterov's look-ahead really works
The look-ahead gradient gives Nesterov the theoretically optimal O(1/k²) rate, visibly beating plain momentum on every problem tested — not just in theory.
⚠️
AdaGrad stalls on dense problems
The cumulative squared gradient denominator grows without bound, so the effective lr shrinks toward zero. RMSProp's EMA solves this cleanly.
📅
Cosine annealing beats everything
Across all 7 optimizers, adding cosine annealing consistently improved final loss vs fixed lr or step decay. The smooth decay avoids abrupt destabilization.
🍌
Rosenbrock is hard for everyone
The narrow curved valley causes all optimizers to struggle. Adam still converges, but slowly. The tiny gradients along the valley floor fool adaptive methods.
🎯
Momentum β=0.9 gives ~3× speedup
On the κ=1000 quadratic, adding β=0.9 momentum reduces iterations to convergence by ~3× vs GD. A small hyperparameter change with a huge practical effect.

Code

Quick Start

from src.landscapes import make_ill_conditioned_quadratic
from src.optimizers import run_all
import numpy as np
import matplotlib.pyplot as plt

# set up a hard problem — condition number 1000
landscape = make_ill_conditioned_quadratic(n=10, kappa=1000)
x0 = np.zeros(10)

# run all 6 optimizers from the same starting point
results = run_all(landscape, x0, n_iter=300)

# plot convergence on a log scale
for name, r in results.items():
    plt.semilogy(r.f_history, label=name)

plt.legend()
plt.xlabel("Iteration")
plt.ylabel("Loss (log scale)")
plt.show()
